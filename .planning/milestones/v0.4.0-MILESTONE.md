## Patterns Established

1. **Triple Verification**: UI check → on-chain ownerOf → PocketBase record
2. **Bilateral Verification**: Capture before/after state for both parties
3. **Serial Test Mode**: `test.describe.configure({ mode: 'serial' })` for dependent tests
4. **Skip-on-Env**: Tests pass/skip gracefully when E2E environment not configured
