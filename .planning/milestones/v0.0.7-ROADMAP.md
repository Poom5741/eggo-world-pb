### Phase 18: Fix LINE OAuth Wallet Creation

**Goal**: Fix wallet auto-creation for LINE OAuth users  
**Depends on**: Nothing (bug fix)  
**Plans**: 2 plans

Plans:

- [x] 18-01: Fix wallet hook (onRecordCreate → onRecordBeforeCreate)
- [x] 18-02: OAuth callback with wallet verification

**Details:**

**Root Cause:** `01-create-wallet.pb.js` hook used `onRecordCreate` with `$apis.requireAuth()` which requires authenticated user. LINE OAuth creates users via `pb.collection('users').create()` WITHOUT auth token, so hook failed silently.

**Fix:** Changed to `onRecordBeforeCreate` which fires before commit and doesn't require authentication. Added wallet verification to line-callback.html. Wallet auto-creation now working for all new LINE OAuth users.

## Milestone Summary

**Key Decisions:**

1. **0xl3 testnet priority** — Chain ID 7117 preferred over legacy BSC testnet (97)
2. **ethers.js v6** — Already installed, smaller bundle, better docs than web3.js
3. **12-block confirmation** — Standard for BSC, balances security vs UX
4. **20% gas buffer** — Prevents out-of-gas failures on variable gas operations
5. **onRecordBeforeCreate** — Set wallet fields BEFORE commit, not after (fixes OAuth)
6. **Non-blocking PB callback on mint** — PB record creation failure logs error but doesn't fail mint
7. **Daily check-in (off-chain)** — Skip complex mini-games for MVP, database only
8. **Polling (not WebSocket)** — Matches PocketBase architecture, simpler state management

**Issues Resolved:**

- Fixed LINE OAuth wallet auto-creation (silent auth check failure)
- Replaced all mock blockchain calls with real contract integration
- Fixed vi.mock test failures blocking test execution
- Achieved 80%+ test coverage across wallet-api and frontend
- Implemented complete NFT mint → register → list → buy flow

**Issues Deferred:**

- Phase 12: feed-egg foodCount validation (moved to Phase 20)
- Phase 19: gas sponsorship documentation + human verification tests (moved to Phase 20)
- Phase 10/17: 10 UAT scenarios requiring manual execution (moved to Phase 20)
- Phase 03: Frontend marketplace verification gaps (legacy, moved to Phase 20)

**Technical Debt Incurred:**

- "Updating..." polling badge visual not verified (infrastructure exists)
- Gas sponsorship inconsistent (mint uses user wallet, buy uses relayer)
