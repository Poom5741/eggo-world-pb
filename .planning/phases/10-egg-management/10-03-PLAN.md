       - species: string
       - element: string
       - generation: number

       - hatchEggTransaction: (eggId: number) => Promise<AnimalData | null>
       - loading: boolean

       - Get toast from useToast()
       - hatchEggTransaction callback with param (eggId: number):

           - **Step 1: Verify egg is ready**
             - Get signer
             - Call getFoodCount(signer, eggId)

           - **Step 2: Call hatchEgg**
             - Call hatchEgg(signer, eggId)
             - Get animalTokenId from transaction
             - Show toast: "Hatching... Wait for confirmation"
           - **Step 3: Wait for confirmation**
             - Wait for transaction receipt (poll every 2s)
             - On success: toast.success("Hatch successful! Your Animal is ready!")
           - **Step 4: Fetch Animal metadata**
             - Call AnimalNFT contract to get animal properties
             - Map rarity from enum to string (0=Common, 1=Rare, 2=Epic, 3=Legendary)
             - Return AnimalData object
         - Catch (err):
           - setError(err.message)
           - toast.error(`Hatch failed: ${err.message}`)
           - Return null
         - Finally: setLoading(false)

    8. Export return object
