# Plan 33-01: Recruitment Bonus USDT Rewards + Multipliers

## Gap: RECRUIT-01

**Problem:** Users who recruit others don't receive Food NFT bonuses or USDT rewards based on their downline size. The spec defines a tiered bonus table with multipliers (×2/×4/×6/×10) but no implementation exists.

**Goal:** Implement `calculateRecruitmentBonus` logic that awards Food NFTs and USDT based on total direct recruits.

## Recruitment Bonus Table (from Functional Spec)

| Your Total Recruits (G1 Direct) | Food Items Rewarded | Multiplier | Bonus (10 items tier) | Bonus (100 items tier) | Bonus (1000 items tier) |
| ------------------------------- | ------------------- | ---------- | --------------------- | ---------------------- | ----------------------- |
| 10 recruits                     | 1 Food NFT          | ×2         | $10                   | $100                   | $1,000                  |
| 100 recruits                    | 1 Food NFT          | ×4         | $20                   | $200                   | $2,000                  |
| 1,000 recruits                  | 1 Food NFT          | ×6         | $30                   | $300                   | $3,000                  |
| 10,000 recruits                 | 1 Food NFT          | ×10        | $50                   | $500                   | $5,000                  |

## Implementation

### 1. Smart Contract: Add to EggNFT.sol

Add recruitment bonus calculation and distribution function:

```solidity
// In EggNFT.sol or a separate RecruitmentBonus.sol

struct RecruitmentTier {
    uint256 minRecruits;
    uint256 foodReward;
    uint256 multiplier;
    uint256 usdtBonus;
}

RecruitmentTier[] public tiers;

function initializeTiers() public onlyOwner {
    tiers.push(RecruitmentTier(10, 1, 2, 10 ether));      // 10 recruits
    tiers.push(RecruitmentTier(100, 1, 4, 20 ether));     // 100 recruits
    tiers.push(RecruitmentTier(1000, 1, 6, 30 ether));    // 1,000 recruits
    tiers.push(RecruitmentTier(10000, 1, 10, 50 ether));  // 10,000 recruits
}

function calculateRecruitmentBonus(address user) public view returns (
    uint256 tier,
    uint256 foodReward,
    uint256 multiplier,
    uint256 usdtBonus
) {
    uint256 directRecruits = getUserDirectRecruits(user);

    // Find highest eligible tier
    uint256 eligibleTier = 0;
    for (uint256 i = 0; i < tiers.length; i++) {
        if (directRecruits >= tiers[i].minRecruits) {
            eligibleTier = i + 1;
            foodReward = tiers[i].foodReward;
            multiplier = tiers[i].multiplier;
            usdtBonus = tiers[i].usdtBonus;
        }
    }

    return (eligibleTier, foodReward, multiplier, usdtBonus);
}

function claimRecruitmentBonus() public {
    require(!hasClaimedRecruitmentBonus[msg.sender], "Already claimed");

    (uint256 tier, uint256 foodReward, uint256 multiplier, uint256 usdtBonus) = calculateRecruitmentBonus(msg.sender);
    require(tier > 0, "No tier reached");

    // Mark as claimed
    hasClaimedRecruitmentBonus[msg.sender] = true;

    // Mint Food NFTs
    for (uint256 i = 0; i < foodReward * multiplier; i++) {
        _mintFoodNFT(msg.sender);
    }

    // Transfer USDT bonus from CoinStor
    usdt.transfer(msg.sender, usdtBonus);

    emit RecruitmentBonusClaimed(msg.sender, tier, foodReward, multiplier, usdtBonus);
}
```

### 2. PocketBase Hook: `33-recruitment-bonus.pb.js`

Create hook at `apps/backend/pb_hooks/33-recruitment-bonus.pb.js`:

```javascript
routerAdd("POST", "/api/v2/claim-recruitment-bonus", (e) => {
  try {
    const requestInfo = e.requestInfo()
    const userId = requestInfo.auth?.id

    if (!userId) {
      return e.json(401, {
        success: false,
        error: { message: "Authentication required", code: "AUTH_REQUIRED" },
      })
    }

    const user = $app.findRecordById("users", userId)

    // Count direct recruits
    const allUsers = $app.findRecordsByFilter("users", "", "-created", 10000, 0)
    let directRecruitCount = 0

    for (let i = 0; i < allUsers.length; i++) {
      const u = allUsers[i]
      if (u.id === userId) continue
      if (u.get("upline_G1") === userId) {
        directRecruitCount++
      }
    }

    // Determine tier
    const tiers = [
      { min: 10, food: 1, multiplier: 2, usdt: 10 },
      { min: 100, food: 1, multiplier: 4, usdt: 20 },
      { min: 1000, food: 1, multiplier: 6, usdt: 30 },
      { min: 10000, food: 1, multiplier: 10, usdt: 50 },
    ]

    let eligibleTier = null
    for (let i = tiers.length - 1; i >= 0; i--) {
      if (directRecruitCount >= tiers[i].min) {
        eligibleTier = tiers[i]
        eligibleTier.tierNumber = i + 1
        break
      }
    }

    if (!eligibleTier) {
      return e.json(400, {
        success: false,
        error: {
          message: `Need at least 10 direct recruits. You have ${directRecruitCount}`,
          code: "TIER_NOT_REACHED",
        },
      })
    }

    // Check if already claimed this tier
    const claimedTier = user.get("claimed_recruitment_tier") || 0
    if (claimedTier >= eligibleTier.tierNumber) {
      return e.json(400, {
        success: false,
        error: { message: "Already claimed this tier bonus", code: "ALREADY_CLAIMED" },
      })
    }

    // Call wallet-api to mint food NFTs and credit USDT
    const walletApiUrl = $os.getenv("WALLET_SRV_URL") || "http://localhost:3001"
    const response = $http.send({
      url: `${walletApiUrl}/api/v1/wallet/claim-recruitment-bonus`,
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        user_address: user.get("wallet"),
        tier: eligibleTier.tierNumber,
        food_count: eligibleTier.food * eligibleTier.multiplier,
        usdt_bonus: eligibleTier.usdt,
      }),
    })

    // Update user's claimed tier
    user.set("claimed_recruitment_tier", eligibleTier.tierNumber)
    $app.save(user)

    e.json(200, {
      success: true,
      data: {
        tier: eligibleTier.tierNumber,
        food_rewarded: eligibleTier.food * eligibleTier.multiplier,
        usdt_bonus: eligibleTier.usdt,
        direct_recruits: directRecruitCount,
      },
    })
  } catch (err) {
    e.json(500, {
      success: false,
      error: { message: err.message, code: "RECRUITMENT_BONUS_FAILED" },
    })
  }
})
```

### 3. Wallet API Endpoint: `claim-recruitment-bonus`

Add to `wallet-api/server.js`:

```javascript
app.post("/api/v1/wallet/claim-recruitment-bonus", async (req, res) => {
  try {
    const { user_address, tier, food_count, usdt_bonus } = req.body

    if (!user_address || !tier || !food_count || !usdt_bonus) {
      return res.status(400).json({
        success: false,
        error: { message: "Missing required fields", code: "VALIDATION_ERROR" },
      })
    }

    // Get user's encrypted private key
    const user = await pocketBase.collection("users").getFirstListItem(`wallet = "${user_address}"`)
    const privateKey = await decryptPrivateKey(user.encrypted_private_key, MASTER_KEY + user.id)

    // Create signer
    const provider = new ethers.JsonRpcProvider(process.env.RPC_URL)
    const signer = new ethers.Wallet(privateKey, provider)

    // Connect to Food NFT contract
    const foodContract = new ethers.Contract(
      process.env.NEXT_PUBLIC_FOOD_NFT_ADDRESS,
      FOOD_NFT_ABI,
      signer
    )

    // Mint Food NFTs
    const foodTx = await foodContract.mintBatch(user_address, food_count)
    await foodTx.wait(12)

    // Transfer USDT bonus (from CoinStor or platform wallet)
    const usdtContract = new ethers.Contract(
      process.env.USDT_CONTRACT_ADDRESS,
      USDT_ABI,
      new ethers.Wallet(process.env.PLATFORM_PRIVATE_KEY, provider)
    )

    const usdtAmount = ethers.parseUnits(usdt_bonus.toString(), 18)
    const usdtTx = await usdtContract.transfer(user_address, usdtAmount)
    await usdtTx.wait(12)

    res.json({
      success: true,
      data: {
        food_transaction_hash: foodTx.hash,
        usdt_transaction_hash: usdtTx.hash,
        tier,
        food_count,
        usdt_bonus,
      },
    })
  } catch (error) {
    res.status(500).json({
      success: false,
      error: { message: error.message, code: "RECRUITMENT_BONUS_FAILED" },
    })
  }
})
```

### 4. Frontend Component: RecruitmentBonusCard

Create at `apps/web/components/dashboard/RecruitmentBonusCard.tsx`:

```typescript
"use client"

import { useState, useEffect } from "react"
import { pb } from "@/lib/pocketbase/client"
import { useIsHydrated } from "@/lib/hooks/use-is-hydrated"
import { Gift, Trophy, ArrowRight } from "lucide-react"
import { Button } from "@/components/ui/button"

interface BonusStatus {
  direct_recruits: number
  current_tier: number
  claimed_tier: number
  can_claim: boolean
  next_tier: { tier: number; min: number; food: number; usdt: number } | null
}

const tierLabels = ["", "Seedling (10)", "Grower (100)", "Farmer (1,000)", "Master (10,000)"]
const tierRewards = [
  "",
  "2 Food NFTs + $10 USDT",
  "4 Food NFTs + $20 USDT",
  "6 Food NFTs + $30 USDT",
  "10 Food NFTs + $50 USDT"
]

export function RecruitmentBonusCard() {
  const isHydrated = useIsHydrated()
  const [status, setStatus] = useState<BonusStatus | null>(null)
  const [claiming, setClaiming] = useState(false)

  useEffect(() => {
    if (!isHydrated) return

    const fetchStatus = async () => {
      try {
        const response = await pb.send("/api/v2/recruitment-bonus-status", {})
        setStatus(response.data)
      } catch (err) {
        console.error("Failed to fetch bonus status:", err)
      }
    }

    fetchStatus()
  }, [isHydrated])

  const handleClaim = async () => {
    setClaiming(true)
    try {
      await pb.send("/api/v2/claim-recruitment-bonus", {})
      // Refresh status
      const response = await pb.send("/api/v2/recruitment-bonus-status", {})
      setStatus(response.data)
    } catch (err) {
      console.error("Failed to claim bonus:", err)
    } finally {
      setClaiming(false)
    }
  }

  if (!isHydrated || !status) return <div className="animate-pulse h-32 bg-muted rounded" />

  return (
    <div className="p-6 rounded-lg bg-card border">
      <div className="flex items-center gap-2 mb-4">
        <Trophy className="h-5 w-5 text-primary" />
        <h3 className="font-semibold">Recruitment Bonus</h3>
      </div>

      <div className="space-y-4">
        <div className="flex justify-between text-sm">
          <span className="text-muted-foreground">Direct Recruits</span>
          <span className="font-medium">{status.direct_recruits}</span>
        </div>

        <div className="flex justify-between text-sm">
          <span className="text-muted-foreground">Current Tier</span>
          <span className="font-medium">{tierLabels[status.current_tier] || "None"}</span>
        </div>

        {status.next_tier && (
          <div className="p-3 rounded bg-muted/50">
            <p className="text-sm text-muted-foreground mb-1">Next Tier</p>
            <div className="flex items-center gap-2">
              <span className="font-medium">{tierLabels[status.next_tier.tier]}</span>
              <ArrowRight className="h-4 w-4" />
              <span className="text-sm">
                Need {status.next_tier.min - status.direct_recruits} more recruits
              </span>
            </div>
          </div>
        )}

        {status.can_claim && (
          <Button onClick={handleClaim} disabled={claiming} className="w-full">
            <Gift className="h-4 w-4 mr-2" />
            Claim {tierRewards[status.current_tier]}
          </Button>
        )}

        {status.claimed_tier === status.current_tier && status.current_tier > 0 && (
          <p className="text-sm text-muted-foreground text-center">
            ✓ Tier {status.current_tier} bonus claimed
          </p>
        )}
      </div>
    </div>
  )
}
```

- [ ] Updates user's claimed_recruitment_tier field

- [ ] Claim button disabled when already claimed or no tier reached
