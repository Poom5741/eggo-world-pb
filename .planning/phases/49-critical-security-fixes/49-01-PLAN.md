<objective>
Fix XOR operator misuse in mint price and breeding fee constants across EggNFT and FoodNFT contracts.

Purpose: The `^` operator in Solidity is bitwise XOR, not exponentiation. Current constants compute incorrect values (e.g., `25 * 10^18` = `25 * 24` = 600 wei instead of 25e18 wei). This makes NFTs virtually free, enabling unlimited minting at near-zero cost.

Output: Corrected price constants using `**` exponentiation operator with explanatory comments.
</objective>
