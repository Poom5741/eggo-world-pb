<objective>
Fix TierBadge token ID reuse vulnerability by implementing monotonically increasing counter instead of hardcoded tier IDs.

Purpose: Current implementation mints NFTs with token IDs equal to tier IDs (1, 2, 3). This means only 3 users can ever claim badges — the second user claiming tier 1 would fail because token ID 1 already exists. This is a deployment-blocking vulnerability that destroys the achievement system.

Output: Monotonically increasing token IDs with tokenId→tierId mapping to preserve tier metadata resolution.
</objective>
