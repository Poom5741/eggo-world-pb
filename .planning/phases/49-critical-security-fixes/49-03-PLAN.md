<objective>
Fix currency mismatch in CommissionDistribution (SEC-03) and add treasury routing with withdrawal path (SEC-04).

Purpose: Current contract credits commissions in USDT but pays out in ETH (claimCommission uses `call{value: ...}`). This drains the wrong balance and permanently loses user funds. Additionally, 46% treasury allocation exists in constants but is never actually routed, locking platform revenue indefinitely.

Output: USDT-only commission system with treasury address, 46% routing, and owner-only withdrawal function.
</objective>
