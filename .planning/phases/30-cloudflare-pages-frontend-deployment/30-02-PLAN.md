  <action>
    Create GitHub Actions workflow for frontend deployment following the deploy-pocketbase.yml pattern but adapted for Cloudflare Pages.
    
    Per D-04 (separate workflow), D-02 (trigger on apps/web/**), D-05 (bun run build):
    
    ```yaml
    name: Deploy Frontend to Cloudflare Pages

    on:
      push:
        branches: [main]
        paths:
          - 'apps/web/**'
          - '.github/workflows/deploy-frontend.yml'
      pull_request:
        branches: [main]
        paths:
          - 'apps/web/**'
          - '.github/workflows/deploy-frontend.yml'

    env:
      CLOUDFLARE_PAGES_PROJECT: eggoworld
      CLOUDFLARE_ACCOUNT_ID: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}

    jobs:
      build-and-deploy:
        runs-on: ubuntu-latest
        permissions:
          contents: read
          deployments: write

        steps:
          - name: Checkout repository
            uses: actions/checkout@v4

          - name: Install Bun
            uses: oven-sh/setup-bun@v2
            with:
              bun-version: latest

          - name: Install dependencies
            run: |
              cd apps/web
              bun install

          - name: Build frontend
            run: |
              cd apps/web
              bun run build
            env:
              NEXT_PUBLIC_POCKETBASE_URL: ${{ vars.NEXT_PUBLIC_POCKETBASE_URL || 'https://pb.eggoworld.io' }}
              NEXT_PUBLIC_TURNSTILE_SITE_KEY: ${{ vars.NEXT_PUBLIC_TURNSTILE_SITE_KEY }}

          - name: Verify build output
            run: |
              test -f apps/web/out/index.html || exit 1
              echo "Build output verified"

          - name: Deploy to Cloudflare Pages
            uses: cloudflare/pages-action@v1
            with:
              apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
              accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
              projectName: ${{ env.CLOUDFLARE_PAGES_PROJECT }}
              directory: apps/web/out
              gitHubToken: ${{ secrets.GITHUB_TOKEN }}
            id: deploy

          - name: Output deployment URL
            run: |
              echo "Deployed to: ${{ steps.deploy.outputs.url }}"
              echo "Preview URL: ${{ steps.deploy.outputs.previewUrl }}"
    ```

    IMPORTANT NOTES:
    - Use `cloudflare/pages-action@v1` for direct deployment (DEPLOY-01)
    - PRs automatically create preview deployments via same workflow (DEPLOY-02)
    - Bun install and build for consistency with local dev (per D-05)
    - Environment vars use GitHub repository variables (`vars.*`) with fallbacks (per D-06)
    - Trigger paths: apps/web/** only (per D-02)
    - secrets.CLOUDFLARE_API_TOKEN and secrets.CLOUDFLARE_ACCOUNT_ID required (user must set these)

    DO NOT use npm — use Bun per D-05. DO NOT change trigger paths — apps/web/** only per D-02.

## Trust Boundaries

| Boundary                          | Description                                |
| --------------------------------- | ------------------------------------------ |
| GitHub Actions → Cloudflare Pages | CI/CD deploys build output to Pages        |
| GitHub Secrets → Workflow         | Secrets injected at runtime, not in code   |
| Preview URL → Public              | PR preview deployments publicly accessible |

## STRIDE Threat Register

| Threat ID | Category               | Component                   | Disposition | Mitigation Plan                                                    |
| --------- | ---------------------- | --------------------------- | ----------- | ------------------------------------------------------------------ |
| T-30-05   | Information Disclosure | CLOUDFLARE_API_TOKEN secret | mitigate    | Use GitHub Secrets, never log token, rotate if compromised         |
| T-30-06   | Tampering              | Workflow file modification  | mitigate    | PR checks verify workflow YAML syntax before merge                 |
| T-30-07   | Spoofing               | Preview deployment URL      | accept      | Preview URLs are temporary, unique per PR, no production data      |
| T-30-08   | Denial of Service      | Build timeout               | mitigate    | Cloudflare Pages default 20min timeout, target <3min per DEPLOY-05 |
