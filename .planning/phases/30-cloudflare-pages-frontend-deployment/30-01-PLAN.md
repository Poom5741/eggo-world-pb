<threat_model>

## Trust Boundaries

| Boundary                      | Description                                                    |
| ----------------------------- | -------------------------------------------------------------- |
| GitHub → Cloudflare Pages     | Source code pushed to GitHub, Cloudflare pulls and builds      |
| Cloudflare CDN → User Browser | Static assets served from edge locations to users              |
| User Browser → PocketBase API | Frontend makes API calls to pb.eggoworld.io (existing backend) |

## STRIDE Threat Register

| Threat ID | Category               | Component                      | Disposition | Mitigation Plan                                                                |
| --------- | ---------------------- | ------------------------------ | ----------- | ------------------------------------------------------------------------------ |
| T-30-01   | Tampering              | GitHub repo → Cloudflare build | mitigate    | Use GitHub Actions for build verification (30-02), not Cloudflare native build |
| T-30-02   | Information Disclosure | NEXT_PUBLIC env vars           | accept      | NEXT_PUBLIC vars are client-visible by design, no secrets in these vars        |
| T-30-03   | Spoofing               | Custom domain                  | mitigate    | Cloudflare SSL/TLS enforced, HTTPS-only, HSTS enabled per CLOUDFLARE_SETUP.md  |
| T-30-04   | Denial of Service      | Edge caching failure           | accept      | Cloudflare's infrastructure handles DDoS, static assets highly resilient       |

</threat_model>
