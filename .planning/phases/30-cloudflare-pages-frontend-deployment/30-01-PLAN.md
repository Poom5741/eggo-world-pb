### Task 03: Create \_headers File for Edge Caching

<read_first>

- `apps/web/public/` directory
  </read_first>

<action>
Create `apps/web/public/_headers` file with the following content:
```
/*
  Cache-Control: public, max-age=3600, s-maxage=86400

/\_next/static/\*
Cache-Control: public, max-age=31536000, immutable

/\*.js
Cache-Control: public, max-age=31536000, immutable

/\*.css
Cache-Control: public, max-age=31536000, immutable

```

This enables:
- 1 hour browser cache, 24 hour edge cache for HTML pages
- 1 year immutable cache for static JS/CSS assets
