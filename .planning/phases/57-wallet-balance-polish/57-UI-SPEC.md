| Role                 | Size     | Weight      | Line Height | Font Family              |

| Card title ("USDT…") | 18px     | 600         | 1.2         | Silkscreen (pixel)       |
| Balance display      | 36px     | 700 (bold)² | 1.2         | Silkscreen (pixel)       |
| Description / Label  | 12px     | 400         | 1.5         | Silkscreen (pixel)       |

**Declared sizes:** 12px, 16px, 18px, 36px (4 sizes)

**Notes:**
¹ `text-2xl md:text-3xl` — responsive from 24px on mobile to 30px on desktop.

³ Button text uses `text-xs` (12px) pixel font. Body text defaults to 16px Plus Jakarta Sans.

## Animation & Transition Contract

| Interaction                     | Animation                                               | Duration | Easing                  | Source                                    |
| ------------------------------- | ------------------------------------------------------- | -------- | ----------------------- | ----------------------------------------- |
| Skeleton → Real content fade-in | CSS opacity transition (`opacity-0` → `opacity-100`)    | 500ms    | `ease-out` (default)    | D-02, CONTEXT.md §Specifics               |
| Skeleton pulse                  | `animate-pulse` (Tailwind CSS pulse keyframes)          | 2s cycle | Tailwind `cubic-bezier` | Existing skeleton.tsx, BuddyChain pattern |
| "Updating..." badge pulse       | `animate-pulse` (existing badge)                        | 2s cycle | Tailwind `cubic-bezier` | D-03, existing wallet page                |
| Sync button spinner             | `animate-spin` on RefreshCw icon                        | 1s cycle | linear                  | Existing wallet page                      |
| Sync button disabled state      | `opacity-50` + `cursor-not-allowed`                     | instant  | —                       | shadcn Button default                     |
| Error → success transition      | Immediate re-render (skeleton fade-in applies on retry) | as above | —                       | Discretion — keep simple                  |
| Reduced motion                  | `prefers-reduced-motion: reduce` → disable animations   | —        | —                       | globals.css line 792-804                  |

**States covered per WALLET-01:**

1. **Loading (initial):** Skeleton card visible → fade-in to real balance on fetch complete
2. **Loading (background poll):** "Updating..." badge visible on card, skeleton NOT shown (D-03)
3. **Success:** Balance number + USD approximation + Sync button
4. **Error:** Destructive Alert with error message + Retry button (link variant)
5. **Empty/Zero:** Balance shows `0.00 USDT` with description — no special empty state needed (balance of 0 is valid data from the hook)
6. **No wallet:** `useWalletPoll` returns `{ usdt: '0', native: '0' }` with no error — displays zero balance naturally

**Refined error copy (from CONTEXT.md §Claude's Discretion):**

- Existing: `"Failed to load balance. Retry"`
- Proposed refinement: `"Balance update failed. The wallet service may be temporarily unavailable."` + `"Retry"` button
- Keep existing behavior: inline destructive Alert (not a full-screen error, not a toast)

## Interaction States

### Balance Card States

```
┌─────────────────────────────────────────┐
│  [State Machine for Balance Card]        │
│                                          │
│  ┌──────────┐    ┌──────────────┐       │
│  │ LOADING  │───→│ SUCCESS      │       │
│  │ (skeleton│    │ (balance +   │       │
│  │  +fade)  │    │  sync btn)   │       │
│  └──────────┘    └──────┬───────┘       │
│       │                 │               │
│       │                 │ (poll fails)  │
│       │                 ▼               │
│       │          ┌──────────────┐       │
│       │          │ ERROR        │       │
│       └─────────→│ (alert +     │       │
│                   │  retry btn)  │       │
│                  └──────┬───────┘       │
│                         │               │
│                    (retry clicked)       │
│                         ↓               │
│                    ┌──────────────┐     │
│                    │ LOADING      │     │
│                    │ (skeleton    │     │
│                    │  +fade-in)   │     │
│                    └──────────────┘     │
└─────────────────────────────────────────┘
```

**Key interaction rules:**

1. **Initial load:** Show skeleton card immediately → once data arrives, fade-in to real balance (500ms opacity transition)
2. **Background poll (already loaded):** Show "Updating..." badge only — do NOT show skeleton again
3. **Error during background poll:** Show destructive Alert below/within card — balance number stays visible (shows last known value)
4. **Retry from error:** Clicking "Retry" fetches fresh data → on success: hide Alert, update balance number with smooth number transition (optional, see discretion)
5. **No wallet address:** Show `0.00 USDT` with no error — wallet page instructions remain visible
