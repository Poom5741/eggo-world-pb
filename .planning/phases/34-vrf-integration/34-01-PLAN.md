# Plan 34-01: VRF Integration for Verifiable Randomness

## Gap: VRF-01

**Problem:** Egg hatching currently uses pseudo-random number generation (block hash or timestamp) which is predictable and manipulable. The spec requires Verifiable Random Function (VRF) for fair, tamper-proof rarity determination.

**Goal:** Replace pseudo-random with Chainlink VRF (or BSC VRF alternative) for egg hatching randomness.

## Analysis

### Current Implementation (Pseudo-random — INSECURE)

```solidity
// Current (DON'T USE)
uint256 randomSeed = uint256(keccak256(abi.encodePacked(block.timestamp, block.prevrandao, eggId)));
```

**Vulnerabilities:**

- Miners/validators can manipulate `block.timestamp`
- `block.prevrandao` is predictable within a block
- Front-running possible if randomness is known before transaction

### Required Implementation (VRF — SECURE)

Two approaches for BSC:

**Option A: Chainlink VRF v2.5** (Recommended for mainnet)

- Proven, widely adopted
- Subscription-based billing in LINK
- ~1-3 minute response time
- Cost: ~$0.25 per request on BSC

**Option B: BNB Greenfield VRF** (BSC native)

- Native to BSC ecosystem
- Lower cost than Chainlink
- Less battle-tested

**Decision:** Use Chainlink VRF v2.5 for reliability and documentation. Can switch to BSC VRF later if cost becomes an issue.

## Implementation

### 1. Smart Contract: Update EggNFT.sol with Chainlink VRF

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@chainlink/contracts/src/v0.8/vrf/VRFConsumerBaseV2.sol";
import "@chainlink/contracts/src/v0.8/vrf/interfaces/VRFCoordinatorV2Interface.sol";
import "@openzeppelin/contracts/access/Ownable.sol";

contract EggNFT is VRFConsumerBaseV2, Ownable {
    VRFCoordinatorV2Interface immutable COORDINATOR;

    // VRF Configuration
    uint64 public subscriptionId;
    bytes32 public keyHash;
    uint32 public callbackGasLimit = 500000;
    uint16 public requestConfirmations = 3;
    uint32 public numWords = 1;

    // Pending requests mapping
    mapping(uint256 => address) public pendingRequests; // requestId => user address
    mapping(uint256 => uint256) public pendingEggs;     // requestId => egg_id

    // VRF Events
    event VRFRequested(uint256 requestId, uint256 eggId);
    event VRFulfilled(uint256 requestId, uint256 randomWord, uint256 eggId);

    constructor(
        address vrfCoordinator,
        uint64 _subscriptionId,
        bytes32 _keyHash
    ) VRFConsumerBaseV2(vrfCoordinator) {
        COORDINATOR = VRFCoordinatorV2Interface(vrfCoordinator);
        subscriptionId = _subscriptionId;
        keyHash = _keyHash;
    }

    /// @notice Update VRF configuration (admin only)
    function setVRFConfig(
        uint64 _subscriptionId,
        bytes32 _keyHash,
        uint32 _callbackGasLimit
    ) external onlyOwner {
        subscriptionId = _subscriptionId;
        keyHash = _keyHash;
        callbackGasLimit = _callbackGasLimit;
    }

    /// @notice Internal hatching function — called by VRF callback
    function _hatchEggWithRandom(uint256 eggId, uint256 randomSeed) internal {
        // Determine rarity from random seed
        uint256 rarityRoll = randomSeed % 100;
        Rarity rarity;

        if (rarityRoll < 60) {
            rarity = Rarity.Common;      // 60%
        } else if (rarityRoll < 85) {
            rarity = Rarity.Rare;        // 25%
        } else if (rarityRoll < 97) {
            rarity = Rarity.Epic;        // 12%
        } else {
            rarity = Rarity.Legendary;   // 3%
        }

        // Determine species from random seed + food history
        uint256 speciesSeed = randomSeed % 1000;
        string memory species = _determineSpecies(speciesSeed, eggId);

        // Mint Animal NFT
        _mintAnimalNFT(eggId, rarity, species);
    }

    /// @notice Request VRF randomness for egg hatching
    function requestHatchRandomness(uint256 eggId) internal returns (uint256 requestId) {
        require(msg.sender == address(this), "Only contract can request");

        requestId = COORDINATOR.requestRandomWords(
            keyHash,
            subscriptionId,
            requestConfirmations,
            callbackGasLimit,
            numWords
        );

        pendingRequests[requestId] = msg.sender;
        pendingEggs[requestId] = eggId;

        emit VRFRequested(requestId, eggId);
        return requestId;
    }

    /// @notice Chainlink VRF callback
    function fulfillRandomWords(
        uint256 requestId,
        uint256[] calldata randomWords
    ) internal override {
        address user = pendingRequests[requestId];
        uint256 eggId = pendingEggs[requestId];

        require(user != address(0), "Invalid request ID");

        uint256 randomSeed = randomWords[0];

        // Clean up
        delete pendingRequests[requestId];
        delete pendingEggs[requestId];

        // Hatch with verifiable random
        _hatchEggWithRandom(eggId, randomSeed);

        emit VRFulfilled(requestId, randomSeed, eggId);
    }
}
```

### 2. Updated hatchEgg Function (Two-Phase Pattern)

```solidity
/// @notice Start egg hatching — requests VRF randomness
function hatchEgg(uint256 eggId) external {
    Egg storage egg = eggs[eggId];

    require(egg.owner == msg.sender, "Not egg owner");
    require(egg.foodCount >= 10, "Need 10 food items");
    require(!egg.isHatched, "Already hatched");

    // Mark as hatching (prevents double-hatch during VRF wait)
    egg.isHatching = true;

    // Request VRF randomness
    uint256 requestId = requestHatchRandomness(eggId);

    emit EggHatchingStarted(eggId, requestId);
}
```

### 3. PocketBase Hook: `34-vrf-hatch.pb.js`

Create hook to handle VRF callback and update PocketBase records:

```javascript
// Poll for VRF fulfillment and update animal_nfts record
routerAdd("POST", "/api/v2/hatch-egg-vrf", (e) => {
  try {
    const requestInfo = e.requestInfo()
    const userId = requestInfo.auth?.id

    if (!userId) {
      return e.json(401, {
        success: false,
        error: { message: "Authentication required", code: "AUTH_REQUIRED" },
      })
    }

    const { egg_id, request_id } = e.parseBody()

    if (!egg_id) {
      return e.json(400, {
        success: false,
        error: { message: "egg_id required", code: "VALIDATION_ERROR" },
      })
    }

    // Call wallet-api to initiate VRF hatch
    const walletApiUrl = $os.getenv("WALLET_SRV_URL") || "http://localhost:3001"
    const response = $http.send({
      url: `${walletApiUrl}/api/v1/wallet/hatch-egg-vrf`,
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        user_id: userId,
        egg_id: egg_id,
      }),
    })

    // Parse response
    let responseData
    if (response.json && typeof response.json === "object") {
      responseData = response.json
    } else if (response.body) {
      let responseBody = response.body
      if (Array.isArray(response.body)) {
        responseBody = ""
        for (let i = 0; i < response.body.length; i++) {
          responseBody += String.fromCharCode(response.body[i])
        }
      }
      responseData = JSON.parse(responseBody)
    }

    if (response.statusCode < 200 || response.statusCode >= 300) {
      throw new Error("VRF hatch failed: " + JSON.stringify(responseData))
    }

    e.json(200, {
      success: true,
      data: {
        request_id: responseData.data.request_id,
        egg_id: egg_id,
        status: "vrf_requested",
        message: "VRF randomness requested. Animal will be minted in 1-3 minutes.",
      },
    })
  } catch (err) {
    e.json(500, {
      success: false,
      error: { message: err.message, code: "VRF_HATCH_FAILED" },
    })
  }
})

// GET endpoint to check VRF hatch status
routerAdd("GET", "/api/v2/hatch-status/:egg_id", (e) => {
  try {
    const eggId = e.request.pathValue("egg_id")

    // Query egg_nfts collection for status
    const egg = $app.findRecordById("egg_nfts", eggId)

    if (!egg) {
      return e.json(404, {
        success: false,

      success: true,
      data: {

        is_hatched: egg.get("is_hatched") || false,
        is_hatching: egg.get("is_hatching") || false,
        animal_id: egg.get("animal_id") || null,
        vrf_request_id: egg.get("vrf_request_id") || null,
      },
    })
  } catch (err) {
    e.json(500, {
      success: false,
      error: { message: err.message, code: "HATCH_STATUS_FAILED" },

  }
})
```

### 4. Wallet API: VRF Hatch Endpoint

Add to `wallet-api/server.js`:

```javascript
app.post("/api/v1/wallet/hatch-egg-vrf", async (req, res) => {
  try {
    const { user_id, egg_id } = req.body

    if (!user_id || !egg_id) {
      return res.status(400).json({
        success: false,
        error: { message: "user_id and egg_id required", code: "VALIDATION_ERROR" },
      })
    }

    // Get user's wallet
    const user = await pocketBase.collection("users").getOne(user_id)
    const privateKey = await decryptPrivateKey(user.encrypted_private_key, MASTER_KEY + user.id)

    const provider = new ethers.JsonRpcProvider(process.env.RPC_URL)
    const signer = new ethers.Wallet(privateKey, provider)

    // Connect to Egg NFT contract
    const eggContract = new ethers.Contract(
      process.env.NEXT_PUBLIC_EGG_NFT_ADDRESS,
      EGG_NFT_ABI,
      signer
    )

    // Call hatchEgg (triggers VRF request)
    const tx = await eggContract.hatchEgg(egg_id)
    const receipt = await tx.wait()

    // Extract VRF request ID from event
    const vrfEvent = receipt.logs.find((log) => {
      try {
        const parsed = eggContract.interface.parseLog(log)
        return parsed.name === "VRFRequested"
      } catch {
        return false
      }
    })

    let requestId = null
    if (vrfEvent) {
      const parsed = eggContract.interface.parseLog(vrfEvent)
      requestId = parsed.args.requestId.toString()
    }

    // Update egg_nfts record in PocketBase
    await pocketBase.collection("egg_nfts").update(egg_id, {
      is_hatching: true,
      vrf_request_id: requestId,
      vrf_transaction_hash: tx.hash,
    })

    res.json({
      success: true,
      data: {
        request_id: requestId,
        transaction_hash: tx.hash,
        egg_id: egg_id,
        status: "vrf_requested",
      },
    })
  } catch (error) {
    res.status(500).json({
      success: false,
      error: { message: error.message, code: "VRF_HATCH_FAILED" },
    })
  }
})

// Poll for VRF fulfillment (called by cron or PocketBase hook)
app.post("/api/v1/wallet/check-vrf-fulfillment", async (req, res) => {
  try {
    const { egg_id, request_id } = req.body

    const provider = new ethers.JsonRpcProvider(process.env.RPC_URL)
    const eggContract = new ethers.Contract(
      process.env.NEXT_PUBLIC_EGG_NFT_ADDRESS,
      EGG_NFT_ABI,
      provider
    )

    // Check if VRF fulfilled event exists
    const filter = eggContract.filters.VRFulfilled(request_id)
    const events = await eggContract.queryFilter(filter)

    if (events.length > 0) {
      const event = events[0]
      const parsed = eggContract.interface.parseLog(event)
      const randomWord = parsed.args.randomWord.toString()
      const eggId = parsed.args.eggId.toString()

      // Get animal_id from contract
      const animalId = await eggContract.getAnimalIdByEgg(eggId)

      // Update PocketBase
      await pocketBase.collection("egg_nfts").update(egg_id, {
        is_hatched: true,
        is_hatching: false,
        animal_id: animalId.toString(),
        hatch_timestamp: new Date().toISOString(),
      })

      res.json({
        success: true,
        data: {
          fulfilled: true,
          random_seed: randomWord,
          animal_id: animalId.toString(),
          egg_id: eggId,
        },
      })
    } else {
      res.json({
        success: true,
        data: {
          fulfilled: false,
          message: "VRF not yet fulfilled",
        },
      })
    }
  } catch (error) {
    res.status(500).json({
      success: false,
      error: { message: error.message, code: "VRF_CHECK_FAILED" },
    })
  }
})
```

### 5. Frontend: VRF Hatch Flow

Update hatch button in `apps/web/app/eggs/page.tsx`:

```typescript
const handleHatch = async (eggId: string) => {
  setHatching(eggId)
  try {
    // Request VRF hatch
    const response = await pb.send("/api/v2/hatch-egg-vrf", {
      body: { egg_id: eggId },
    })

    toast.success("VRF randomness requested! Animal will appear in 1-3 minutes.")

    // Poll for fulfillment
    const pollInterval = setInterval(async () => {
      const status = await pb.send(`/api/v2/hatch-status/${eggId}`, {})

      if (status.data.is_hatched) {
        clearInterval(pollInterval)
        toast.success("Egg hatched! Check your animals.")
        refreshEggs()
      }
    }, 15000) // Poll every 15 seconds

    // Stop polling after 5 minutes
    setTimeout(() => clearInterval(pollInterval), 5 * 60 * 1000)
  } catch (error) {
    toast.error("Failed to start hatching")
  } finally {
    setHatching(null)
  }
}
```

## Acceptance Criteria

- [ ] EggNFT.sol uses Chainlink VRF v2.5 for randomness
- [ ] `hatchEgg()` initiates VRF request and marks egg as `isHatching`
- [ ] `fulfillRandomWords()` callback mints Animal NFT with verifiable random rarity
- [ ] VRF configuration (subscriptionId, keyHash) is admin-configurable
- [ ] POST `/api/v2/hatch-egg-vrf` initiates VRF hatch via wallet-api
- [ ] GET `/api/v2/hatch-status/:egg_id` returns hatch status
- [ ] Wallet API polls for VRF fulfillment and updates PocketBase
- [ ] Frontend shows "Hatching..." state with 1-3 minute estimate
- [ ] Frontend polls for completion and refreshes on fulfillment
- [ ] Rarity distribution matches spec: Common 60%, Rare 25%, Epic 12%, Legendary 3%

## Dependencies

- Chainlink VRF subscription on BSC (requires LINK tokens)
- VRF coordinator address for BSC testnet/mainnet
- Key hash for BSC VRF
- `egg_nfts` collection needs `is_hatching`, `vrf_request_id`, `vrf_transaction_hash` fields
- `animal_nfts` collection must exist (Phase 21)
- Existing egg hatching logic must be refactored to two-phase pattern
