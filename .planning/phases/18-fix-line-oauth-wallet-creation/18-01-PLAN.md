**Why this fixes the issue:**

- `onRecordCreate` fires AFTER the record is committed and requires `$apis.requireAuth()` to work
- LINE OAuth creates users via `pb.collection('users').create()` WITHOUT an auth token (line 154 of line-callback.html)
- The auth check fails, so the wallet creation code never executes
- `onRecordBeforeCreate` fires BEFORE commit and doesn't require authentication, so it will trigger for all user creation including OAuth
