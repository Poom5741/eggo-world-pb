## Test User Wallet Discovery

The `user_wallets` PocketBase collection stores wallet addresses for each user. The e2e-setup.ts Anvil addresses (0xf39Fd..., 0x709979...) are REFERENCES from the Docker test environment — the actual wallet addresses for test_seller and test_buyer in the local PB dev instance WILL BE DIFFERENT. They must be discovered at runtime:

```bash
curl -s http://localhost:8090/api/collections/user_wallets/records \
  -H "Authorization: Bearer <pb_admin_token>" | \
  jq '.items[] | {user_id, wallet_address, usdt_balance}'
```

Get PB admin token:

```bash
curl -s -X POST http://localhost:8090/api/admins/auth-with-password \
  -H "Content-Type: application/json" \
  -d '{"identity":"admin@eggo.local","password":"admin123"}' | \
  jq -r '.token'
```
