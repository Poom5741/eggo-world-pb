# Phase 26-01: Fix Rarity Filter Syntax

## Objective

Fix the rarity filter in the animal marketplace hook to use PocketBase 0.23.x compatible single-quote syntax instead of double quotes.

**Purpose:** PocketBase 0.23.x requires single quotes for string filter values. The current implementation uses double quotes which causes the filter to fail silently.

**Output:** Working rarity filter that correctly filters animal listings by selected rarity types.

## Tasks

### Task 1: Fix Rarity Filter Quote Syntax

<read_first>
- apps/web/hooks/use-animal-marketplace.ts (Line 56)
</read_first>

<action>
Change the rarity filter string construction from double quotes to single quotes.

**Current code (Line 56):**
```typescript
const rarityFilter = rarities.map((r) => `rarity = "${r}"`).join(" || ")
```

**Fixed code:**
```typescript
const rarityFilter = rarities.map((r) => `rarity = '${r}'`).join(" || ")
```

This is a single-line change. The PocketBase filter syntax requires single quotes around string values: `rarity = 'Common'` instead of `rarity = "Common"`.

</action>
