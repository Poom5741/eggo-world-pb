# Phase 26-03: Prevent Duplicate Listings

## Objective

Add validation to prevent users from creating multiple active listings for the same animal. This requires both backend validation in the PocketBase hook and frontend UX to disable the List button.

**Purpose:** Currently, a user can list the same animal multiple times, creating duplicate active listings. This causes marketplace confusion and potential purchase conflicts.

**Output:** Backend rejects duplicate listings with clear error. Frontend checks existing listings and disables List button accordingly.

**Step 2: Add useEffect to check for existing listing on mount (after state declarations):**
```typescript
useEffect(() => {
  if (!animal || !open) return
  
  const checkExistingListing = async () => {
    setCheckingListing(true)
    try {
      const response = await fetch(`/api/v2/list-animal?animal_id=${animal.animal_id}`, {
        method: 'GET',
        headers: {
          'Authorization': pb.authStore.token
        }
      })
      
      if (response.ok) {
        const result = await response.json()
        // Check if any active listing exists for this animal
        const hasActive = result.data?.some?.(
          (listing: any) => listing.animal_id === animal.animal_id && listing.status === 'active'
        )
        setHasActiveListing(hasActive || false)
      }
    } catch (err) {
      console.error('Failed to check existing listings:', err)
    } finally {
      setCheckingListing(false)
    }
  }
  
  checkExistingListing()
}, [animal, open, pb.authStore.token])
```
