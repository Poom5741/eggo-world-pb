# Phase 26-04: Fix Animal Detail Route Path

## Objective

Fix the incorrect route path in AnimalListingsSection that causes 404 errors when clicking on animal listing cards.

**Purpose:** The current code navigates to `/marketplace/animal/${listing.id}` but the actual route structure is `/marketplace/[id]/` (no `/animal/` subdirectory). This mismatch causes a 404 crash when users try to view animal details.

**Output:** Clicking an animal listing card correctly navigates to the marketplace detail page.

## Tasks

### Task 1: Fix Route Path in handleCardClick

<read_first>

- apps/web/components/marketplace/AnimalListingsSection.tsx (Lines 155-158)
  </read_first>

<action>
Change the router.push path from `/marketplace/animal/${listing.id}` to `/marketplace/${listing.id}`.

**Current code (Lines 155-158):**

```typescript
const handleCardClick = (listing: any) => {
  // Navigate to detail page or open buy dialog
  router.push(`/marketplace/animal/${listing.id}`)
}
```

**Fixed code:**

```typescript
const handleCardClick = (listing: any) => {
  // Navigate to detail page (supports egg, food, and animal NFTs via nftType param)
  router.push(`/marketplace/${listing.id}`)
}
```

The `/marketplace/[id]/` route already supports all NFT types (egg, food, animal) through the `nftType` query parameter. The existing MarketplaceDetailClient.tsx handles type detection automatically.
