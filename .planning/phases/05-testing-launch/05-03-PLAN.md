<task type="checkpoint:human-action">
  <name>task 2: Deploy smart contracts to BSC mainnet</name>
  <action>
    This task requires manual execution due to private key security.
    
    **Pre-deployment checklist:**
    1. Verify you're on BSC mainnet (chainId 56), NOT testnet (97)
    2. Confirm deployment wallet has sufficient BNB for gas (5+ BNB recommended)
    3. Verify .env.local has PRODUCTION private key (not testnet key)
    4. Double-check contract constructor parameters
    
    **Deployment steps:**
    1. Navigate to contracts directory:
       ```bash
       cd contracts
       ```
    
    2. Create/update .env.local with mainnet config:
       ```
       BSC_RPC_URL=https://bsc-dataseed.binance.org
       PRIVATE_KEY=<YOUR_PRODUCTION_PRIVATE_KEY>
       BSC_NETWORK=mainnet
       ```
    
    3. Verify network in foundry.toml:
       ```toml
       [etherscan]
       mainnet = { key = "${BSCSCAN_API_KEY}" }
       ```
    
    4. Run deployment script:
       ```bash
       forge script script/Deploy.s.sol:Deploy --rpc-url $BSC_RPC_URL --broadcast --verify -vvvv
       ```
    
    5. Verify contracts on BscScan (manual step if --verify fails):
       - Go to https://bscscan.com/verifyContract
       - Paste contract address and source code
       - Verify constructor args
    
    6. Update deployment-addresses.json with mainnet addresses
    
    **Post-deployment verification:**
    - Test each contract function on BscScan "Read Contract" tab
    - Verify owner is your deployment address
    - Confirm USDT token address is correct (BEP-20 USDT: 0x55d398326f99059fF775485246999027B3197955)
  </action>
