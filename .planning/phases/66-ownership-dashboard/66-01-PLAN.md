## Threat Model

### Trust Boundaries

| Boundary            | Description                                                      |
| ------------------- | ---------------------------------------------------------------- |
| Client → BSC RPC    | Untrusted client makes on-chain queries via viem readContract    |
| Client → MetaMask   | User wallet signs acceptOwnership transaction locally            |
| TreasuryGate → Page | Access control enforced via CommissionDistribution.owner() check |

### STRIDE Threat Register

| Threat ID | Category               | Component           | Disposition | Mitigation Plan                                                                        |
| --------- | ---------------------- | ------------------- | ----------- | -------------------------------------------------------------------------------------- |
| T-66-01   | Spoofing               | RPC endpoint        | mitigate    | Use official BSC RPC endpoints via viem's bsc chain config                             |
| T-66-02   | Tampering              | Address display     | mitigate    | viem's Address type enforces EIP-55 checksum validation                                |
| T-66-03   | Tampering              | Transaction         | mitigate    | Chain ID validation via useMetaMask().chainId, viem includes EIP-155 replay protection |
| T-66-04   | Information Disclosure | Contract access     | mitigate    | TreasuryGuard verifies CommissionDistribution.owner() before rendering page            |
| T-66-05   | Denial of Service      | Single card failure | mitigate    | Isolated error state per contract card, one failing RPC doesn't block entire UI        |
| T-66-06   | Tampering              | ABI injection       | mitigate    | Minimal ABI in contracts.json, only functions needed for ownership queries             |
| T-66-07   | Spoofing               | MetaMask provider   | mitigate    | Rely on viem's window.ethereum validation, useMetaMask hook handles provider events    |
| T-66-SC   | Tampering              | Package installs    | accept      | No new packages (viem installed in Phase 65, slopcheck: [OK])                          |
