# Plan 21-01: Breeding Dialog UI

## Objective

Create a complete breeding dialog system with two-step flow: animal selection and breeding confirmation. Reuses FeedDialog pattern for consistency. Implements D-01, D-02, D-03 from CONTEXT.md.

## Context

- FeedDialog.tsx provides the dialog pattern to replicate (two-step flow, claymorphism styling)
- AnimalCard.tsx shows how to display animal info (species, rarity, generation)
- Backend hook at `18-breed-animals.pb.js` expects POST to `/api/v2/breed-animals`
- Breeding fee is 5 USDT (constant in hook)
- Rarity probability: 70% max parent rarity, 20% +1 tier, 10% -1 tier
