| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Spoofing | /api/v2/deposit/poll | mitigate | `e.requireAuth()` enforces authentication; user_address validated against authenticated user's wallet |
| T-13-02 | Tampering | Deposit record creation | mitigate | Database unique constraint on tx_hash prevents duplicate credits; balance updated only after successful deposit save |
| T-13-03 | Repudiation | Deposit polling | mitigate | All poll attempts logged via console.log; last_polled_block stored in database for audit trail |
| T-13-04 | Information Disclosure | Deposit history | mitigate | PocketBase listRule: `@request.auth.id = user.id` ensures users only see own deposits |
| T-13-05 | Denial of Service | eth_getLogs RPC calls | accept | Polling interval 30s limits request rate; BSC testnet has no cost per call |
| T-13-06 | Elevation of Privilege | Confirmation checker | mitigate | Confirmation logic runs server-side in hook; user cannot manipulate block_number or confirmations field |
