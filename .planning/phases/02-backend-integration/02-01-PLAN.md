<task type="auto">
  <name>task 2: Write 21-sync-events.pb.js hook with block polling</name>
  <files>apps/backend/pb_hooks/21-sync-events.pb.js</files>
  <action>
    Create event sync hook following CONTEXT.md decisions D-05 through D-20:

    **Structure:**
    1. Import config from EGGO_CONFIG (blockchain RPC URLs, contract addresses)
    2. onAppBootstrap: Initialize sync on PocketBase startup
    3. setInterval: Poll every 30 seconds (D-14)
    4. For each new block: fetch with events, filter by contract addresses (D-15)
    5. Process events with syncWithRetry (3 retries, exponential backoff per D-09)
    6. On success: update sync_state.lastProcessedBlock atomically (D-08, D-16)
    7. On critical error: set status='error', log full context, stop sync (D-13, D-20)

    **Event handlers (5 events from D-06):**
    - syncEggMinted: Update egg_nfts collection, set owner
    - syncFoodMinted: Update food_nfts collection, set owner
    - syncAnimalMinted: Update animal_nfts with rarity, species, generation
    - syncEggHatched: Mark egg as hatched, link to animal_nfts
    - syncCommissionDistributed: Update commission_records, increment user balances

    **Idempotency:** Each handler MUST check if already processed (per CONTEXT.md "Event Handler Idempotency")

    **Code patterns:**
    - Thai comments (per AGENTS.md conventions)
    - Try-catch with structured error responses
    - Use $http.send for RPC calls (PocketBase JS VM)
    - Use pb.collection() for DB operations
    - Reference 01-create-wallet.pb.js for hook structure

    **Configuration:**
    - RPC URL: EGGO_CONFIG.blockchain.rpcUrl (add to 00-config.pb.js if missing)
    - Contract addresses: from 01-01-SUMMARY.md
    - Polling interval: 30000ms
    - Max retries: 3

  </action>
