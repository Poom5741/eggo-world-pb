### Task 3.1: Implement Recruitment Bonus Hook

**Objective:** Add Food NFT reward logic to registration hook when recruit thresholds reached

**Steps:**

1. Read existing hook: `apps/backend/pb_hooks/07-register-user.pb.js`
2. Locate where `total_direct_recruits` is incremented (around line 99-101)
3. Add threshold checking logic after increment:

   ```javascript
   const thresholds = [
     { recruits: 10, foodItems: 10 },
     { recruits: 100, foodItems: 50 },
     { recruits: 1000, foodItems: 100 },
     { recruits: 10000, foodItems: 200 },
   ]

   const newCount = currentCount + 1

   // Check if new count crosses a threshold
   const eligibleReward = thresholds.find(
     (t) => newCount >= t.recruits && currentCount < t.recruits
   )

   if (eligibleReward) {
     // Grant Food NFTs
     grantFoodNFTs(user.id, eligibleReward.foodItems)
   }
   ```

4. Create `grantFoodNFTs` helper function:

   ```javascript
   function grantFoodNFTs(userId, itemCount) {
     // Create food NFT records in PocketBase
     const foodTypes = ["grain", "fish", "insects", "herbs"]
     const itemsPerType = Math.floor(itemCount / 4)
     const remainder = itemCount % 4

     for (let i = 0; i < 4; i++) {
       const count = itemsPerType + (i < remainder ? 1 : 0)
       if (count > 0) {
         $app.collection("food_nfts").create({
           user: userId,
           food_type: foodTypes[i],
           quantity: count,
           source: "recruitment_bonus",
         })
       }
     }

     console.log(`Granted ${itemCount} Food NFTs to user ${userId} for recruitment milestone`)
   }
   ```

5. Add error handling (log but don't fail registration):
   ```javascript
   if (eligibleReward) {
     try {
       grantFoodNFTs(user.id, eligibleReward.foodItems)
     } catch (bonusErr) {
       console.error("Failed to grant recruitment bonus:", bonusErr)
       // Don't fail registration - bonus is best-effort
     }
   }
   ```
6. Test hook with mock data:
   - Simulate registration at 9 recruits → no bonus
   - Simulate registration at 10 recruits → 10 Food NFTs granted
   - Verify Food NFTs created in PocketBase

**Acceptance Criteria:**

- [x] Hook checks thresholds on each new recruit
- [x] Food NFTs granted automatically at 10/100/1,000/10,000
- [x] Bonus logic wrapped in try-catch (non-blocking)
- [x] `source: 'recruitment_bonus'` set for tracking
- [x] Hook still functions correctly after modification
- [x] No registration failures if bonus grant fails
