### Task 2.4: Integrate Tutorial into Dashboard

**Objective:** Trigger tutorial on first dashboard visit and dismiss correctly

**Steps:**

1. Import tutorial in dashboard page:

   ```typescript
   import dynamic from "next/dynamic"

   const OnboardingTutorial = dynamic(() => import("@/components/tutorial/OnboardingTutorial"), {
     loading: () => null,
   })
   ```

2. Add state management:

   ```typescript
   const [showTutorial, setShowTutorial] = useState(false)

   useEffect(() => {
     if (typeof window !== "undefined") {
       const completed = localStorage.getItem("tutorial_completed")
       if (!completed) {
         setShowTutorial(true)
       }
     }
   }, [])
   ```

3. Render tutorial conditionally:
   ```tsx
   {
     showTutorial && <OnboardingTutorial onDismiss={() => setShowTutorial(false)} />
   }
   ```
4. Ensure tutorial only shows after hydration (use `useIsHydrated()` hook if exists)
5. Test tutorial flow:
   - Clear localStorage
   - Visit `/dashboard`
   - Verify tutorial appears
   - Navigate through steps
   - Dismiss tutorial
   - Refresh page (tutorial should not appear again)

**Acceptance Criteria:**

- [x] Tutorial appears on first `/dashboard` visit

- [x] Tutorial respects hydration state (no SSR mismatch)
- [x] Tutorial dismiss sets localStorage flag correctly

- [x] Dashboard page loads correctly with/without tutorial
