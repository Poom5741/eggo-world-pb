<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner key → Contract | Private key stored in wallet-api env var, used to sign admin transactions |
| Admin API → Wallet-API | Backend calls wallet-api endpoint, must authenticate as admin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-01 | Spoofing | pauseMarketplace | mitigate | `onlyOwner` modifier ensures only owner key can call |
| T-29-02 | Tampering | setPlatformFee | mitigate | Input validation caps fee at 10%, prevents fee manipulation |
| T-29-03 | Information Disclosure | Owner private key | mitigate | Key stored in wallet-api env var, never exposed to frontend or PocketBase |
| T-29-04 | Elevation of Privilege | unpauseMarketplace | mitigate | `onlyOwner` + `whenPaused` modifiers prevent unauthorized unpause |
</threat_model>
