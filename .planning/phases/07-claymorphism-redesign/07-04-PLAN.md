Update Alert component with claymorphism styling and variants.

Add variant support to alert.tsx using cva:

```typescript
import { cva, type VariantProps } from 'class-variance-authority'

const alertVariants = cva(
  "relative w-full rounded-clay-md p-4 shadow-clay-md transition-shadow",
  {
    variants: {
      variant: {
        default: 'bg-background text-foreground',
        destructive:
          'bg-destructive/10 text-destructive shadow-clay-md',
        warning:
          'bg-amber-500/10 text-amber-600 shadow-clay-md',
        success:
          'bg-green-500/10 text-green-600 shadow-clay-md',
      },
    },
    defaultVariants: {
      variant: 'default',
    },
  }
)

function Alert({
  className,
  variant,
  ...props
}: React.ComponentProps<'div'> & VariantProps<typeof alertVariants>) {
  return (
    <div
      role="alert"
      className={cn(alertVariants({ variant }), className)}
      {...props}
    />
  )
}
```

Keep AlertTitle and AlertDescription unchanged.

Key changes:

- `rounded-clay-md` (24px radius) for soft edges
- `shadow-clay-md` for depth
- New warning/success variants for better UX
- Maintains existing destructive variant
