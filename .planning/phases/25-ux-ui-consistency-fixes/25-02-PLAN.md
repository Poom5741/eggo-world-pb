## Plan 25-02-02: Typography Standardization

### Step 1: Add Typography Utility Classes

**File:** `apps/web/app/globals.css`

```css
@layer utilities {
  /* Typography utilities */
  .font-heading {
    @apply font-headline;
  }

  .font-body {
    @apply font-body;
  }

  .font-pixel {
    @apply font-[var(--font-pixel)];
  }

  /* Responsive text sizes */
  .text-heading-xl {
    @apply text-2xl md:text-3xl lg:text-4xl font-black;
  }

  .text-heading-lg {
    @apply text-xl md:text-2xl lg:text-3xl font-black;
  }

  .text-heading-md {
    @apply text-lg md:text-xl lg:text-2xl font-bold;
  }

  /* Section headers */
  .text-section {
    @apply text-xl md:text-2xl lg:text-3xl;
  }

  .text-subsection {
    @apply text-lg md:text-xl lg:text-2xl;
  }
}
```

### Step 2: Migrate Typography Usage

**Pattern:** Replace `font-[var(--font-pixel)]` with semantic utility classes

| Element Type    | Before ❌                           | After ✅                       |
| --------------- | ----------------------------------- | ------------------------------ |
| Page titles     | `font-[var(--font-pixel)] text-3xl` | `font-heading text-heading-xl` |
| Section headers | `font-[var(--font-pixel)] text-xl`  | `font-heading text-section`    |
| Body text       | `font-[var(--font-pixel)] text-sm`  | `font-body text-sm`            |
| Labels/captions | `font-[var(--font-pixel)] text-xs`  | `font-body text-xs`            |

**Files to Audit:** 23 files with 151 matches of `font-[var(--font-pixel)]`

### Step 3: Remove Legacy font-pixel-style Class

If `font-pixel-style` class exists in globals.css, deprecate it and migrate all usages.

- `variant="clay"` — Standard cards, dashboard widgets, list items
- `variant="clay-lg"` — Featured content, hero cards
- `variant="clay-xl"` — Modal dialogs, prominent sections

### Step 3: Migrate Div-Based Cards to Card Component

**Migration Pattern:**

```tsx
// BEFORE ❌
<div className="bg-surface-container rounded-xl clay-card p-6 shadow-clay-md">
  <CardContent>Content</CardContent>
</div>

// AFTER ✅
<Card variant="clay" className="shadow-clay-md">
  <CardHeader>Header</CardHeader>
  <CardContent>Content</CardContent>
</Card>
```

### Step 4: Add Missing Card Variants to Component

If the Card component doesn't support `variant` prop, extend it:

```typescript
interface CardProps extends HTMLAttributes<HTMLDivElement> {
  variant?: 'clay' | 'clay-lg' | 'clay-xl'
}

const cardVariants = cva(
  "rounded-clay-xl transition-colors",
  {
    variants: {
      variant: {
        clay: "bg-surface-container shadow-clay-md p-6",
        "clay-lg": "bg-surface-container shadow-clay-lg p-8 rounded-clay-2xl",
        "clay-xl": "bg-surface-container shadow-clay-xl p-10 rounded-claw-3xl",
      },
    },
  }
)

export function Card({ variant = 'clay', className, ...props }: CardProps) {
  return <div className={cn(cardVariants({ variant }), className)} {...props} />
}
```
