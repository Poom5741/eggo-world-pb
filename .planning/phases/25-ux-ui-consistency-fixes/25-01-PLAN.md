## Plan 25-01-04: Accessibility Fixes (WCAG 2.2 AA)

### Sub-plan 25-01-04a: Form Label Association

**Files:** `/app/page.tsx`, `/join/page.tsx`

```tsx
// BEFORE ❌
<input type="email" placeholder="Email address" />

// AFTER ✅
<input
  type="email"
  aria-label="Email address"
  placeholder="Email address"
/>
```

```tsx
// BEFORE ❌
<label>Username</label>
<input type="text" id="" />

// AFTER ✅
<label htmlFor="username">Username</label>
<input type="text" id="username" />
```

### Sub-plan 25-01-04b: Keyboard Accessible Interactive Elements

**File:** `/app/page.tsx` (social media icons)

```tsx
// BEFORE ❌ — div is not focusable
<div className="w-10 h-10 ... cursor-pointer">
  <span>share</span>
</div>

// AFTER ✅ — button is keyboard accessible
<button
  type="button"
  aria-label="Share on social media"
  className="w-10 h-10 ... focus:ring-2 focus:ring-primary"
>
  <span className="material-symbols-outlined" aria-hidden="true">share</span>
</button>
```

### Sub-plan 25-01-04c: Skip Navigation Link

**File:** `app/layout.tsx`

Add skip navigation link before main content:

```tsx
<a
  href="#main-content"
  className="sr-only focus:not-sr-only ... focus:absolute focus:top-4 ..."
>
  Skip to main content
</a>
<main id="main-content">{children}</main>
```

### Sub-plan 25-01-04d: Dead Link Remediation

**Files:** `/app/page.tsx` (8 links), `/join/page.tsx` (1 link)

Create `/app/coming-soon/page.tsx`:

```tsx
export default function ComingSoonPage() {

    <div className="min-h-screen flex items-center justify-center">
      <h1 className="text-4xl font-black mb-4">Coming Soon</h1>

    </div>

```

Replace all `href="#"` with `href="/coming-soon"` and add `aria-disabled` where appropriate.

### Sub-plan 25-01-04e: Missing Focus States

**Files:** `TopNav.tsx`, `header.tsx`, icon-only buttons across the app

Add consistent focus ring pattern to all interactive elements:

```tsx
className = "... focus:outline-none focus:ring-2 focus:ring-primary focus:ring-offset-2"
```
