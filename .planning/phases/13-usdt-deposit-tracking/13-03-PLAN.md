The test file needs to be rewritten from scratch (RED PHASE file is 703 lines of defunct TDD tests). New structure:

```
13-track-deposit.test.js
├── Configuration Mocks
│   ├── EGGO_CONFIG with MockUSDT address
│   ├── Mock $app (findFirstRecordByData, save, findRecordsByFilter)
│   └── Mock fetch (RPC responses + PocketBase API)
│
├── Test Suite: Background Poller
│   ├── Starts on hook load (setInterval called)
│   ├── Polls every EGGO_CONFIG.blockchain.pollingInterval
│   └── Uses sync_state for block tracking
│
├── Test Suite: Deposit Detection
│   ├── Detects new MockUSDT Transfer events
│   ├── Parses amount (6 decimal USDT)
│   ├── Creates "pending" deposit record
│   └── Skips non-user transfers
│
├── Test Suite: Confirmation Tracking
│   ├── Increments confirmations each poll
│   ├── Transitions to "confirmed" at 12 blocks
│   ├── Updates wallet balances on confirmation
│   └── Does NOT update balance before 12 blocks
│
├── Test Suite: Duplicate Detection
│   ├── Skips existing tx_hash (unique constraint)
│   ├── Handles idempotent re-polling
│   └── No duplicate balance updates
│
├── Test Suite: Reorg Detection
│   ├── Detects block hash mismatch
│   ├── Marks deposit as "failed"
│   └── Reverts balance on confirmed reorg
│
├── Test Suite: Manual Endpoint
│   ├── POST /api/v2/deposit/poll
│   ├── Auth required (401 without token)
│   ├── Input validation (bad address → 400)
│   ├── Returns deposits + new_balance
│   └── Returns 404 for unknown wallet
│
└── Test Suite: Error Handling
    ├── RPC connection error → graceful fallback
    ├── Invalid RPC response → error logged
    ├── Missing sync_state → initializes at block 0
    └── Bad config → caught and logged
```
