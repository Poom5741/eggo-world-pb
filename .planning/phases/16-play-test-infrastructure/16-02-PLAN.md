<steps>
1. T16.05: Create daily_checkins collection schema
   - JSON file at apps/backend/collections/daily_checkins.json
   - Fields: user (relation), check_in_date (date), streak_count (number), reward_claimed (bool),
     food_nft_id (relation -> food_nfts, optional), bonus_type (select, optional),
     bonus_food_ids (json, optional)
   - Unique index on (user, check_in_date)

2. T16.07: Update users collection schema
   - Add field: `streak_count` (number, default 0, min 0)
   - Add field: `longest_streak` (number, default 0, min 0)
   - Add field: `badges` (json, default [])

3. T16.06: Create 27-play-checkin.pb.js hook
   - POST /api/v2/play/check-in:
     a. requireAuth
     b. Parse body
     c. Check today's check-in exists → if yes, return cooldown info (time until midnight)
     d. Find yesterday's check-in → if exists, streak = yesterday.streak + 1; else streak = 1
     e. Create daily_checkins record
     f. Create food_nft record (random food_type, assign sequential food_id)
     g. Update user.streak_count, user.longest_streak if needed
     h. If streak == 7: create 3 bonus food_nfts, set bonus_type = "7_day_streak"
     i. If streak == 30: create 10 bonus food_nfts, update user.badges include "daily_champion"
     j. Return: { success, data: { streak, reward, bonus, cooldown_until } }
   - GET /api/v2/play/check-in/status:
     a. requireAuth
     b. Find today's check-in
     c. Return: { can_claim, streak_count, cooldown_until, next_bonus_at }
     </steps>
