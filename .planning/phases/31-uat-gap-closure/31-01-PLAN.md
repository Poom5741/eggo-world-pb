  <action>
    The polling badge implementation already exists in both files. The issue is that the polling state duration is too brief (~1 second during fetch).

    Add a minimum display duration mechanism to make the badge visible for at least 2 seconds:

    1. In `egg-card.tsx`:
       - Add `useState` for `showPollingBadge` that tracks minimum display time
       - When `polling` becomes true, set `showPollingBadge = true`
       - When `polling` becomes false, use `setTimeout` to delay setting `showPollingBadge = false` by 2000ms
       - Clear timeout on cleanup to prevent memory leaks
       - Render badge based on `showPollingBadge` instead of just `polling`

    2. In `featured-egg-hero.tsx`:
       - Apply the same minimum display duration mechanism
       - Ensure the badge is positioned prominently (top-right of egg container)

    Implementation pattern:
    ```tsx
    const [showPollingBadge, setShowPollingBadge] = useState(false)
    const pollingTimeoutRef = useRef<NodeJS.Timeout | null>(null)

    useEffect(() => {
      if (polling) {
        setShowPollingBadge(true)
        // Clear any existing timeout
        if (pollingTimeoutRef.current) {
          clearTimeout(pollingTimeoutRef.current)
        }
      } else if (showPollingBadge) {
        // Delay hiding the badge by 2 seconds
        pollingTimeoutRef.current = setTimeout(() => {
          setShowPollingBadge(false)
        }, 2000)
      }
    }, [polling, showPollingBadge])

    // Cleanup on unmount
    useEffect(() => {
      return () => {
        if (pollingTimeoutRef.current) {
          clearTimeout(pollingTimeoutRef.current)
        }
      }
    }, [])
    ```

    Then change the badge rendering from `{polling && ...}` to `{showPollingBadge && ...}`.
