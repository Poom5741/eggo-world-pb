## Current Implementation Analysis

**AnimalSelectionGrid.tsx line 59:**

```tsx
const filteredAnimals = animals.filter((a) => a.animal_id !== excludeAnimalId)
```

**Problem:**

- When parent1 is selected, `excludeAnimalId` is set to parent1's `animal_id` (which is 0)
- Filter condition: `a.animal_id !== 0` — ALL animals have `animal_id = 0`, so ALL are excluded
- Result: `filteredAnimals = []` → "No animals available"

**Data issue:**

- Backend creates animals with `animal_id = 0` instead of the blockchain token_id
- This is a data integrity issue, but frontend can add defensive handling

**Fix approach (Option C from CONTEXT.md):**

- Add fallback: if `animal_id` is 0, use the unique `id` (PocketBase record ID) for filtering
- This is defensive programming that handles the current data state
