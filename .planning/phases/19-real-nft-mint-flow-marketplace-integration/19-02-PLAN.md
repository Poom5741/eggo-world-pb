  <action>
Create apps/web/app/mint/page.tsx as a new client component with the following features per D-04:

1. **Authentication check**: Redirect to /auth/login if not authenticated (use useEffect + isAuthenticated())
2. **Balance check**: Fetch user's USDT balance from PocketBase user_wallets collection
   - Use `pb.collection('user_wallets').getList(1, 1, { filter: 'owner="${userId}"' })`
   - Show balance in UI: "Your balance: X USDT"
   - Disable mint button if balance < 25 USDT
3. **Mint UI**:
   - Show mint price: "25 USDT" (large, prominent)
   - Optional referrer ID input field (reuse pattern from MintEggModal.tsx)
   - Mint button with loading state
   - Transaction progress indicator after mint is triggered
4. **Transaction flow**:
   - On mint click: Call wallet-api endpoint

   ```typescript
   const walletApiUrl = process.env.NEXT_PUBLIC_WALLET_API_URL || "http://localhost:3001"
   const response = await fetch(`${walletApiUrl}/mint-egg`, {
     method: "POST",
     headers: { "Content-Type": "application/json" },
     body: JSON.stringify({
       userId: user.id,
       wallet: user.wallet,
       eggId: 1, // Default egg ID (can be configurable later)
       eggNftAddress: process.env.NEXT_PUBLIC_EGG_NFT_ADDRESS,
       referrerAddress: referrerId || undefined,
     }),
   })
   ```

   - Show progress states: "Preparing transaction..." → "Waiting for confirmation (0/12 blocks)..." → "Confirmed!"
   - On success: Show txHash with BSCScan link, redirect to /eggs after 3 seconds
   - On error: Show error message with retry button (per D-06)

5. **Design**: Use claymorphism design system (clay-card, clay-button variants from globals.css)
6. **Layout**: Use LayoutWithoutNav wrapper for consistency with other pages

Key implementation details:

- Use useState for: loading, error, txHash, balance, referrerId, confirmationProgress
- Use useEffect for: auth check, balance fetch
- Show confirmation progress with polling (poll wallet-api for tx status every 5 seconds until 12 blocks)
- BSCScan URL: `https://rpc.0xl3.com/tx/${txHash}` for testnet
- After successful mint, redirect: `router.push('/eggs?highlight=${tokenId}')`

IMPORTANT:

- Do NOT use window.ethereum or MetaMask (constraint: no browser wallets)
- All signing happens server-side via wallet-api
- Use existing claymorphism components (Button, Input, Alert from @/components/ui)
- Follow MintEggModal.tsx patterns but improve with real wallet-api integration
- Page must be fully client-side rendered ('use client' directive)
