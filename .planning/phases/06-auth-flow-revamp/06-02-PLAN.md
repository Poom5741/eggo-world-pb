## Trust Boundaries

| Boundary                  | Description                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------ |
| LINE OAuth → `/auth/line` | `?email=&password=` params from line-callback.html — used only in PB authWithPassword POST |
| sessionStorage → router   | `redirectTo` value used as navigation target — same-origin only                            |

## STRIDE Threat Register

| Threat ID | Category          | Component                                         | Disposition | Mitigation Plan                                                                                                                               |
| --------- | ----------------- | ------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- | --- | ------------------------------------------------------------------- |
| T-06-04   | Open Redirect     | `redirectTo` from sessionStorage in /auth/line    | accept      | sessionStorage is same-origin only; value set by our own middleware (pathname) — cannot be injected by attacker                               |
| T-06-05   | Spoofing          | `?email=&password=` params in /auth/line callback | accept      | Params are passed to PocketBase authWithPassword — PocketBase validates credentials. Invalid creds fail with auth error, not a security issue |
| T-06-06   | Denial of Service | Direct navigation to /auth/line without params    | mitigate    | Guard: `if (!email                                                                                                                            |     | !password) { router.replace('/auth/login') }` prevents page hanging |

</threat_model>
